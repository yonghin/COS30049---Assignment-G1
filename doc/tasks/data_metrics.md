- [ ] 准备 `dashboard_classification_metrics.json`、`dashboard_roc_metrics.json`、`dashboard_confusion_matrices.json`、`dashboard_clustering_metrics.json`
- [ ] 定义静态文件格式与后端返回结构匹配
