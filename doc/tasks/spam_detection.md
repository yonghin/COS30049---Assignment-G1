# Module: Spam Detection Page

## 目标
实现垃圾邮件检测页面，包括文本输入、文件上传、模型选择、预测请求、结果展示与导出。

## 最小可执行任务
- [ ] 创建 `SpamDetection.jsx` 页面骨架，并添加两个输入模式 Tab
- [ ] 实现文本输入模式：多行文本框、字符计数、10~10000 字符校验
- [ ] 实现文件上传模式：`.txt` 和 `.eml` 文件接收、大小限制 2MB、客户端读取内容并预览
- [ ] 创建模型选择 `ToggleButtonGroup`，支持多选且至少选择一个模型
- [ ] 实现提交按钮，调用 `POST /api/spam/predict`，显示加载进度条并防止重复提交
- [ ] 实现结果区域，使用 `SpamResultCard.jsx` 渲染每个模型返回结果
- [ ] 实现 CSV 导出按钮，将当前提交结果下载为 CSV
- [ ] 添加客户端错误提示：输入校验、模型未选择和后端错误
- [ ] 编写单元测试：表单校验、模型选择、请求触发、结果渲染、CSV 导出
